# 3D Chrome Dino AI Slop

Chrome Dino, 3D AI slop version. Exactly that.

![Chrome Dino, 3D AI slop version](screenshots/screenshot.png)

```bash
npm install
npm run dev
```

On the first launch, choose your dinosaur. The choice is saved in this browser.
