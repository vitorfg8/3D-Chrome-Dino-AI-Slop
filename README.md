# Dino 2.5D

Corrida no deserto no espírito do jogo do dinossauro, com câmera lateral e modelos 3D.

```bash
npm install
npm run dev
```

Na primeira abertura, escolha o dinossauro. A escolha fica salva neste navegador.

O código deste jogo está sob a licença MIT. Veja [LICENSE](LICENSE). Os modelos em `public/models/` ficam de fora e seguem as licenças abaixo.
